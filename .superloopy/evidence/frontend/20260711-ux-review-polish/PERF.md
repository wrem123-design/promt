## 성능 보완 사항

- 이미지는 `loading="lazy"`로 로드하고, 갤러리는 무한 스크롤 또는 페이지 모드를 선택할 수 있음.
- 검색 중에는 상단 검색 입력 DOM을 유지하고 본문만 갱신해 한글 IME 끊김과 불필요한 전체 렌더를 줄임.
- 지연된 무한 스크롤 작업은 상세 화면이나 모달로 이동하면 취소됨.
- 브라우저 이미지 최적화 설정으로 표시·분석·썸네일 크기를 분리함.

위 값은 로컬 실행 기준이며 네트워크 배포 성능을 대표하지 않는다. 별도 빌드 도구나 패키지 구성이 없는 앱이므로 Lighthouse 번들은 실행하지 않았다.
