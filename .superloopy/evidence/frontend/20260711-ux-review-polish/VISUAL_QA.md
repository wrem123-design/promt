## 상호작용·접근성

- 검색 입력 시 지우기 버튼이 활성화되고, 지우기 후 값이 비워지며 검색 입력으로 포커스가 돌아옴.
- 설정은 `role="dialog"`와 `aria-labelledby`를 갖고, 열린 직후 포커스가 모달 내부에 위치함.
- 설정 탭 13개가 탭 역할과 선택 상태를 제공함.
- Escape로 모달이 닫히고, 카드에는 Enter·Space 키 동작과 명시적 포커스 링이 적용됨.
- 현재 페이지에는 `aria-current="page"`, 토글 필터에는 `aria-pressed`가 적용됨.
- 최종 새 탐색 세션의 브라우저 콘솔: 오류 0, 경고 0.
- 서버 확인 전에는 연결 전용 화면만 표시해 갤러리 변경 동작을 노출하지 않음.
- 오래된 임시본과 손상된 임시본을 각각 주입해 다시 열었을 때 둘 다 제거되고 서버 저장 상태와 64개 초기 카드 창이 정상 복구됨.

## 구현 정합성

- `DESIGN.md` 토큰 검사: PASS, 위반 0.
- 390px에서는 2열 카드, 단일 열 제어부, 전체 화면형 모달 규칙을 적용함.
- 768px에서는 상단 바가 두 줄로 바뀌고 검색이 전체 폭을 사용함.
- 1280px에서는 브랜드·검색·주요 동작이 한 줄에 배치됨.

## 캡처 제한

이미지 캡처 과정에서 Codex 데스크톱이 종료되는 것으로 보인다는 사용자 피드백이 있어 PNG 증거는 생성하지 않았다. 대신 같은 실제 브라우저 세션에서 폭, overflow, 포커스, ARIA, 콘솔 상태를 수집했다.
